# Presentation Brief

## Summary
A 4-slide visual deck for a dev audience explaining (1) what an agentic coding harness is in 2026, and (2) what clew is — the artefact memory + code workflow layer that feeds the harness. Style modelled on BCG / Bain / McKinsey: bold claims, minimal text, strong graphics.

## Goal
Leave developers understanding two things: (a) the harness, not the model, is the performance lever, and (b) clew is the harness's long-term memory — the structured knowledge layer that makes the agent coherent across sessions.

## Audience
Dev colleagues. Technically fluent. Familiar with LLMs and coding agents. Unfamiliar with formal harness anatomy or what clew does.

## Tone
Authoritative, graphic-first, terse. No prose. One big idea per slide. Consulting-quality layout: wide whitespace, strong typographic hierarchy, single visual per content slide.

## Key Messages
1. The model is the engine. The harness is the car. Same model + better harness = 2× the result.
2. The harness has 6 layers: Memory, Knowledge, Tools, Controls, Observability, Safety — wrapped around the execution loop.
3. clew is the harness's long-term memory: every artefact (VISION → PRD) has a stable ID and traceable reference — the agent always knows where it is and why.
4. The workflow: Read clew → Plan → Code → Validate → Commit back to clew. Deterministic and repeatable.

## Slide Outline

- Slide 2: The Agentic Harness — anatomy diagram (harness wrapping the model + execution loop)
- Slide 3: clew — the artefact stack as a traceable graph
- Slide 4: The Dev Workflow — the 5-step agent loop
