The Build Workflow · End to end

From PRD to merged code: two fresh-session gates, then autonomy.

Business context and discovery are done; the roadmap gives one PRD per epic. The loop below runs per PRD.

1
Spec ready
already done
Delivery roadmap → one PRD per epic
Each PRD states what must be true
PRD in hand
2
Align & plan
fresh session
agent-grill-me: agent grills you ~10 Q on impl & architecture
you answer → shared mental model
agent writes the implementation plan
Plan drafted
3
Verify the plan
fresh session
agent-peer-review: findings ranked critical → low
you resolve the ones needing guidance → amend
ralph audit: plan is autonomously runnable
Audit green
4
Execute & ship
separate CLI
agent-ralph-loop ralph.sh: fresh agent per increment
implement → test gate → commit, until done
run CI on the finished work
Merged
Two fresh-session checks (grill-me before, peer-review after) keep me and the agent aligned; the loop only runs once the plan is proven autonomous.
