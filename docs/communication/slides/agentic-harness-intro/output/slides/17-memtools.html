Memory · The tooling

The memory tools are real. They stop at recall.

A whole ecosystem now gives agents memory, even relational memory. What none of it ships is a traceable model of the product that stays coherent across refactors.

Flat recall
Mem0 · LangMem · vector DBs
Facts, preferences, and past chats, retrieved by similarity. Commodity, bolt-on in an afternoon.
Flat and lossy; misses the relationships.
Relational memory
Zep / Graphiti · Cognee
Temporal knowledge graphs: entities and relationships, not just snippets. Real, and benchmark-backed.
Built for conversation and business facts, not your architecture.
Coding-agent memory
Cursor · Claude Code · Cline · Aider
Flat rules files and auto-noted facts. Windsurf's own docs: “rules only, not codebase architecture.” Aider rebuilds its code map each run.
Facts and rules, or a map rebuilt each run; never a durable model.
The gap
None ships a referentially-enforced, traceable model of strategy, architecture, and decisions that stays coherent across refactors. They remember facts and snippets, not what must be true about the product. Cross-session coherence is still, per the 2026 survey, “largely unsolved.”
