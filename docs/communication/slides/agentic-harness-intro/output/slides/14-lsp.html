LSP: a capability the agent reaches, not another transport.

The Language Server Protocol gives a model IDE-grade understanding of code. It is reached through CLI, MCP or API, and it is the protocol MCP's own spec says it took inspiration from.

What inspired MCPdesign heritage · not a call path
LSP M editors × N languages → M + N
MCP M agents × N tools → M + N
MCP's spec says it “takes some inspiration from” LSP: it shares the client-server JSON-RPC and the same M-by-N to M+N bet, refocused from code analysis to tool execution.
