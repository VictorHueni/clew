LSP: a capability the agent reaches, not another transport.

The Language Server Protocol gives a model IDE-grade understanding of code. It is reached through CLI, MCP or API, and it is the very pattern MCP was modelled on.

What LSP gives an agent
Go to definition
Find references
Hover & types
Diagnostics
Rename symbol
Workspace symbols
grep / CLI returns text matches, line by line.
LSP returns the program's semantic graph: what is defined where, what calls what, what is type-broken.
Capability, not transport
CLI MCP API LSP
You reach LSP through a transport: a CLI wrapper, an lsp-mcp server, or its own JSON-RPC. The transport is how; LSP is what.
Where MCP came from
LSP M editors × N languages → M + N
MCP M agents × N tools → M + N
MCP is explicitly modelled on LSP: same client-server JSON-RPC, refocused from code analysis to tool execution. The pattern already worked once.
