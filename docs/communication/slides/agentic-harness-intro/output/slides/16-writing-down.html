Semantic memory · The one big file

Writing it down isn't memory either.

Semantic memory is what the agent knows about your project: the AGENTS.md and CLAUDE.md it reads in at the start of every session.

Where it breaks
OpenAI built a 1M-line product with zero hand-written code. At that scale, they found one big AGENTS.md broke down, four ways:
AGENTS.mdONE BIG FILE
+ 900 more rules · no one can tell which still apply

Too much guidance, none
Rots silently

OpenAI's fix: they replaced it with a ~100-line table of contents over a structured docs/ tree. Memory has to be a checkable map, not a flat file you hope holds.
