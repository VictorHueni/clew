The Lever · The other two gaps

Memory was one of three. Tools and control are the other two.

The same harness that starves memory also under-tools the agent and skips its control layer. On the lever these rank #1 and #2; memory is only #3.

#1
Tools
read · run · search · sandbox
The gapA model with no tools can only talk. It can't read the repo, run the tests, search the web, or touch a sandbox.
Too few tools and it works blind.
Too many or flaky ones and it thrashes, picks wrong, and burns the context.
The leverageRanked #1. The right, reliable tools move performance more than any prompt or model swap.
#2
Control layer
context · execution · recovery (middleware)
The gapLeft to loop on its own, an agent drifts, repeats itself, and fails silently. Nothing curates the window, drives the loop, or recovers from error.
No context curation, so the window rots.
No execution control, so loops run away.
No recovery, so wrong answers ship silently.
The leverageRanked #2. The middleware that curates context, drives the loop, and verifies is what makes the agent reliable.
Tools, control, memory: three layers the model can't supply. None of them is the model itself.
