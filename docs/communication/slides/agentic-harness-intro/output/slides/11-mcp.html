Tools · The protocol

MCP: one protocol for every tool an agent can reach.

The open standard Anthropic shipped in November 2024. Think USB-C for AI: expose a tool through one server, and every MCP client can call it.

Through MCP, each server exposes three primitives — invoked by the model, read by the app, run by the user
Toolsmodel-controlled
The model invokes them to act (a human approves). The verbs.
e.g.
query a database call an API run a CLI command
Resourcesapp-controlled
Read-only data the client loads as context, by URI. The nouns.
e.g.
documents database records logs
Promptsuser-controlled
Templates the user triggers, often as slash commands. The workflows.
e.g.
slash commands git commit msg guided workflows
Solves the N-by-M problem. Without a standard, M apps each wire N tools → M×N bespoke connectors. With MCP it is M + N: write a server once, every client uses it.
