Where it breaks
Keeping it all is too costly. >90% of tokens go to re-stuffing full history each turn.
More memory, noisier recall. The more you retain, the harder the right memory is to find.
Stale memories mislead. Old context isn't just bloat; it points the agent the wrong way.
What to forget is unsolved. Even scored by importance, recency and relevance, "learned forgetting" is still open (2026).
The fix: treat retention as a decision, not a default. Choosing what's worth keeping needs a model of what matters, which is exactly what no off-the-shelf store has.
