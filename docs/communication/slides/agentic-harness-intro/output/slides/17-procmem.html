Where it breaks
Discovery rides on one sentence. Claude picks from 100+ skills using only each description; a vague one never fires.
The metadata is never free. Every description permanently shares the context budget.
It rots silently. Bundled instructions drift; the only guardrail is "avoid time-sensitive info."
The eager alternative is worse. Codex AGENTS.md and Aider load every turn, no relevance gate.
The fix: a curated, sharply-described, version-controlled skill set. The procedure layer rewards structure, not accumulation.
