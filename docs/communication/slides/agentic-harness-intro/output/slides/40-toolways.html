Appendix · Tools

CLI, MCP & API: three ways in, combined per task.

Same goal, different sweet spot. The harness uses all three, matched to the job, then minds MCP's one real tax.

CLI
shell + filesystem, via a Bash tool
The local build / test / commit loop
Composable, token-cheap, tools the model already knows (git, docker)
Must be installed; unstructured text; no discovery
MCP
a standardized server protocol
Standardized access to external systems
Discoverable & reusable across clients; wire once, every app uses it
Tool defs loaded upfront → context bloat
API
a direct HTTP / REST / SDK call
Hot paths where control & speed matter
Full control, best latency, exact bespoke fit
Bespoke wiring per service (the N×M tax); you own auth & retries
One agent · three mechanisms · chosen per task
MCP's one real tax: context
50K–134K tokens of tool defs loaded before the request is read; task success falls 62→44% when all 65 servers load at once. arXiv 2508.16260
The fix: progressive disclosure
Load tools on demand (code execution / Tool Search), not all upfront. ~85% less context; tool-selection 49→74%. Anthropic
