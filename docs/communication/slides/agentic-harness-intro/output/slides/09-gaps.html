The Lever · The other two gaps

Memory was one of three. Tools and control are the other two.

The same harness that starves memory also under-tools the agent and skips its control layer. Each one moves performance on its own, with the model held fixed.

Tools
read · run · search · sandbox
The gapA model with no tools can only talk: it can't read the repo, run the tests, or touch a sandbox.
Dump every tool in the prompt and tool-selection accuracy falls to 13.6%; retrieve only the relevant ones and it jumps to 43.1%.
Too many or overlapping tools distract the agent and bloat the window.
The leverageChange only the tool interface, same model weights: SWE-agent lifts GPT-4 Turbo from 7.3% to 18.0% on SWE-bench Lite.
Control layer
context · execution · recovery (middleware)
The gapLeft to loop on its own, an agent drifts, repeats failing tool calls, and ships wrong answers silently.
Context is a finite attention budget: recall drops as the window fills, so curating it is the engineer's #1 job.
Nothing decides what enters the window, when to retry, or how to recover.
The leverageAdd a verify-and-retry loop, same model: Reflexion lifts HumanEval pass@1 from 80% to 91%.
Tools, control, memory: three layers the model can't supply. None of them is the model itself.
