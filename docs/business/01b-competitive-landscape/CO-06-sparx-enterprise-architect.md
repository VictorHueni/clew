# CO-06 · Sparx Enterprise Architect

**Indirect** competitor and the incumbent closest to clew's *breadth* claim: one repository
spanning business processes, strategy, requirements, data, application, and technology with
typed relationships and end-to-end traceability. Escalated to Tier-1 watch status by its
**official MCP server (2026)** — an EA incumbent explicitly moving onto "agents need
architectural context" ground.

## ICP / Target segments

- Enterprise/system architects and BA teams in organizations standardized on UML / SysML /
  BPMN / ArchiMate modeling, typically mid-to-large enterprises with dedicated architecture
  functions. (Explicitly out of clew's v1 segment per [Lean Canvas §2](../02a-lean-canvas.md).)

## Value proposition

- The whole enterprise — strategy to technology — modeled in one traceable repository, **so
  that** impact and dependency questions are answerable across layers.

## Go-to-market motion / Pricing

| Aspect | Detail | Evidence |
|---|---|---|
| Model | Commercial perpetual/subscription licenses, editions-tiered; channel + direct | [sparxsystems.com](https://sparxsystems.com/products/ea/) · 2026-07-21 |

## Product / capability scope

- Multi-notation modeling (UML/SysML/BPMN/ArchiMate); requirements management built in;
  cross-layer typed relationships + traceability views; team model repositories; now
  MCP-mediated agent query access.

## SWOT — relative to clew

| Dimension | Items | Confidence |
|---|---|---|
| Strengths (vs us) | Only shipping product with near-R1 breadth; decades of maturity; installed base; official agent access story since 2026. | Tested |
| Weaknesses (vs us) | Binary/DB model repository — not markdown, not git-diffable, unreadable without the tool; artefacts are diagram elements, not prose documents (a persona is a box, not a researched narrative); agent access is token-metered MCP round-trips — the economics wave 1 explicitly rejected; heavyweight for solo agent-first builders. | Tested |
| Opportunities (for them) | Deepening the MCP layer + AI authoring could make "EA repository as agent memory" credible for teams already on Sparx. | Assumed |
| Threats (they pose) | Blocks clew's expansion path upmarket; a "Sparx Lite for agent-first devs" (or aggressive MCP UX) would attack from above with brand credibility. | Assumed |

## Strategic implications for us

- Segment boundary is the defense: clew stays local-first/file-native for builders Sparx will
  never serve cheaply — keep the token-economics contrast explicit and measured.
- Monitor MCP-server adoption signals (forums, integrations) at each refresh.
